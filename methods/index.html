Protocol

The GitHub tree and the Zenodo archive carry the same layout: experiment code, edit vectors, per-cell operating curves, and the R figure pipeline. Model checkpoints and the CounterFact / zsRE fact files are third-party and are not redistributed.

Environment used for the shipped numbers

Python 3.13.7, numpy 2.2.6, scipy 1.16.2, torch 2.12.1 (CUDA 13.0), transformers 5.12.1. Plots additionally need R with jsonlite, ggplot2, and tikzDevice.

Two-phase measurement

Each ROME cell is produced by experiments/merging_m0.py:

  • Phase 1 dumps per-edit keys, values, and residuals (phase1_vectors.npz) plus a closed-form geometry table.
  • Phase 2 merges groups at g ∈ {2, 3, 5, 10, 20, 50, 100}, writes rg_measurements.npz and an operating-curve table. Qualification at a (g, seed) cell requires non-negligible damage, no argmax saturation, a coherence check, and partial ρ ≥ 0.15.

experiments/merging_editors.py is the editor-general analogue (MEMIT, AlphaEdit; ROME is the fp64 equivalence anchor). Drivers expect MODEL_DIR and local fact files. All analysis scripts below are CPU-only and readresults/ with no GPU.

Rebuild tables from the shipped arrays

Several scripts resolve results/merging relative to the process working directory. From the archive root:

ln -s ../results code/results
cd code
python3 experiments/rg_map_evidence_consolidate.py
python3 experiments/rg_signed_reanalysis.py --refix
python3 experiments/rg_crossterm_alignment.py --bundles all
python3 experiments/rg_matched_dose_spread.py
python3 experiments/rg_gain_law.py
python3 experiments/rg_gain_holdout.py
python3 experiments/rg_admission_benefit.py

Per-cell re-score of one bundle:

python3 experiments/merging_m0.py \
  --rg_phase2_dir ../results/merging/Llama-3.2-1B_L12_RG

Public plots:

cd figures
Rscript make_figures.R
make
